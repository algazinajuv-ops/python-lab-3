# Лабораторная работа №3. Каталог объектов

## Описание проекта

Проект представляет собой каталог учебных аудиторий, реализованный на языке Python.

Каталог позволяет добавлять, удалять и получать объекты по уникальному идентификатору, осуществлять поиск по названию и категории, сохранять данные в JSON-файл и восстанавливать их из файла.

## Структура проекта

- `classroom_catalog/`
  - `__init__.py` — инициализация пакета.
  - `models.py` — модель учебной аудитории и проверка инвариантов.
  - `catalog.py` — реализация каталога и операций над объектами.
  - `errors.py` — пользовательские исключения.
  - `storage.py` — сохранение и загрузка каталога.
- `tests/`
  - `test_models.py` — тестирование модели.
  - `test_catalog.py` — тестирование операций каталога.
  - `test_storage.py` — тестирование сохранения и загрузки.
- `pyproject.toml` — конфигурация проекта.
- `README.md` — документация проекта.

## Модель данных

Учебная аудитория представлена классом `Classroom`, реализованным с использованием декоратора `@dataclass`.

| Поле | Тип | Описание |
|---|---|---|
| `item_id` | str | Уникальный идентификатор |
| `name` | str | Название аудитории |
| `category` | str | Категория аудитории |
| `year` | int | Год |
| `floor` | int | Этаж |
| `capacity` | int | Вместимость |
| `occupied` | bool | Состояние занятости |

Проверка инвариантов выполняется в методе `__post_init__` при создании объекта.

Строковые поля должны быть непустыми, год должен принадлежать установленному диапазону, этаж должен находиться в диапазоне от 1 до 7, вместимость должна быть положительным целым числом, а состояние занятости — логическим значением.

При нарушении инвариантов выбрасывается исключение `InvalidItemError`.

## Функциональность каталога

Для хранения объектов используется словарь, ключами которого являются уникальные идентификаторы аудиторий.

| Метод | Назначение |
|---|---|
| `add(item)` | Добавление аудитории |
| `get(item_id)` | Получение аудитории по ID |
| `remove(item_id)` | Удаление аудитории |
| `find_by_category(category)` | Поиск по категории |
| `find_by_name(name)` | Поиск по названию без учёта регистра |
| `__len__()` | Получение количества объектов |
| `__iter__()` | Итерация по объектам |
| `__contains__(item_id)` | Проверка наличия идентификатора |

Дублирование идентификаторов запрещено.

Методы поиска возвращают новые списки объектов, не предоставляя прямого доступа к внутреннему словарю каталога.

Итерация выполняется в порядке добавления объектов. Порядок является детерминированным благодаря использованию словаря Python.

## Временная сложность

| Операция | Средняя временная сложность |
|---|---|
| Добавление | O(1) |
| Получение по ID | O(1) |
| Удаление | O(1) |
| Проверка наличия ID | O(1) |
| Получение количества объектов | O(1) |
| Поиск по категории | O(n) |
| Поиск по названию | O(n) |
| Полный обход каталога | O(n) |

Здесь n — количество объектов в каталоге. Сложность поиска по названию указана при условии ограниченной длины строк.

## Хранение данных

Сохранение и загрузка реализованы в модуле `storage.py`.

Функция `save(catalog, path)` преобразует объекты в словари с помощью `asdict()` и сохраняет их в JSON-файл.

Функция `load(catalog, path)` считывает данные, проверяет структуру документа и версию формата, восстанавливает объекты и заменяет содержимое каталога.

Текущая версия формата — 1.

Пример содержимого JSON-файла:

    {
        "format_version": 1,
        "items": [
            {
                "item_id": "101",
                "name": "Компьютерный класс",
                "category": "Лаборатория",
                "year": 2020,
                "floor": 1,
                "capacity": 30,
                "occupied": false
            }
        ]
    }

### Атомарность загрузки

При загрузке все объекты сначала добавляются во временный каталог.

Содержимое исходного каталога заменяется только после успешной проверки и восстановления всех объектов.

Если в процессе загрузки возникает исключение, исходный каталог остаётся неизменным.

## Обработка исключений

Все предметные исключения наследуются от базового класса `CatalogError`.

- `InvalidItemError` — некорректные данные объекта или аргумента.
- `DublicateIDError` — повторяющийся идентификатор.
- `ItemNotFoundError` — объект не найден.
- `UnsupportedVersionError` — неподдерживаемая версия формата.
- `CorruptedFileError` — повреждённый JSON или некорректное содержимое файла.

## Пример использования

    from classroom_catalog.models import Classroom
    from classroom_catalog.catalog import Catalog
    from classroom_catalog.storage import save, load

    catalog = Catalog()

    room = Classroom(
        "101",
        "Компьютерный класс",
        "Лаборатория",
        2020,
        1,
        30,
        False
    )

    catalog.add(room)

    print(catalog.get("101"))
    print(len(catalog))
    print("101" in catalog)
    print(catalog.find_by_name("компьютерный"))

    save(catalog, "catalog.json")

    new_catalog = Catalog()
    load(new_catalog, "catalog.json")

    print(list(new_catalog))
